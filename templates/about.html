Tentang FruitScan

Sistem klasifikasi buah berbasis Kecerdasan Buatan menggunakan algoritma Random Forest

Deskripsi Proyek

FruitScan adalah aplikasi web berbasis Flask yang mengimplementasikan algoritma Random Forest untuk mengklasifikasikan jenis buah dari gambar. Proyek ini merupakan bagian dari Tugas 8 Praktikum Kecerdasan Buatan di Program Studi Teknik Informatika, Universitas Bale Bandung.


Model dilatih menggunakan dataset Fruits 360 dari Kaggle yang berisi ribuan gambar dari berbagai jenis buah, kemudian di-deploy dalam sebuah aplikasi web yang memungkinkan pengguna mengklasifikasikan buah hanya dengan mengupload gambar.

Cara Kerja Sistem
1
Input Gambar

Pengguna mengupload gambar buah melalui antarmuka web (drag & drop atau pilih file).

2
Preprocessing

Gambar di-resize ke ukuran 32×32 piksel, dikonversi ke format RGB, lalu dinormalisasi ke rentang [0,1] dan di-flatten menjadi vektor fitur.

3
Prediksi Random Forest

Vektor fitur dimasukkan ke model Random Forest (200 pohon keputusan). Setiap pohon memberikan vote, hasil akhir ditentukan berdasarkan mayoritas voting.

4
Output Hasil

Sistem menampilkan label kelas buah, tingkat kepercayaan (confidence), dan top-5 prediksi alternatif.
